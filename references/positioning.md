# 定位 → 风格：从产品推导整套规范

风格从产品里长出来，不从模板里挑。先写简报，再把简报换算成 7 个旋钮，旋钮再落到具体 token。每一个决定都要能说出「因为产品是 X，所以 Y」。

## 1. 简报（先问清，问不到就写出假设）

```
产品：一句话说清做什么、给谁用
场景：什么时候、在哪、一天打开几次、一次停留多久
信任：涉不涉及钱、健康、隐私、不可撤销的操作
人群：年龄、熟练度、特殊需要（老人、孩子、强光户外、单手）
设备：主力设备 + 必须照顾的其他设备（桌面 / 平板 / 手机 H5 / 小程序 / 客户端）
既有资产：品牌色、Logo、字体、现有设计系统或组件库
气质：3 个形容词 + 1 个反例（「不要像 ××」）
```

用户只给一句话时，不要连环追问。最多问一轮最关键的 1–2 个问题（通常是「信任」和「设备」），其余写成假设放在方案开头，用户一眼能改。

## 2. 七个旋钮（1–5）

| 旋钮 | 1 | 3 | 5 | 落到哪些 token |
|---|---|---|---|---|
| 温度 | 冷灰石墨，中性色相 ~255 | 几乎无色偏 | 暖纸米色，中性色相 ~70 | `--neutral`、`--tint`、阴影色 |
| 能量 | 低彩度，主色只用在 1 处 | 主色用于主操作和选中 | 高彩度，可加第二点缀色 spice | `--chroma`、主色覆盖面积 |
| 密度 | 大留白，行高 64+ | 舒适，行高 44–48 | 紧凑，行高 32–36，信息并排 | `--s-*`、控件高度、字号 |
| 圆润 | 近直角 2/4/6px | 8/12/20px | 胶囊按钮 12/20/28px | `--r-control/card/panel` |
| 景深 | 只用细线分层 | 细线 + 轻阴影 | 玻璃、实色投影、3D | `--sh-*`、`--hl-inset`、blur |
| 动势 | calm，无回弹 | snappy，轻微回弹 | bouncy，明显回弹 | `--e-move/--d-move`、`--spring-k/c` |
| 装饰 | 无特效，靠字和留白 | 1 个招牌特效 | 粒子、贴纸、插画都可上 | effects.md 的特效预算 |

旋钮是相对量，不是打分。一个产品通常只有 2–3 个旋钮在两端，其余在中间；七个全在两端的风格会吵。

## 3. 推导顺序：信任 > 频率 > 调性

旋钮之间打架时按这个顺序让步。

1. **信任**。钱、健康、隐私、删除这类场景：对比度拉满、能量 ≤3、装饰 ≤2、关键操作不回弹、状态要说清原因。可爱品牌也一样，付款那一页收着做。
2. **频率**。一天用 8 小时的工具（后台、IDE、客服台）：密度 ≥3、动效短（≤300ms）、装饰 ≤2，惊喜看多了就是噪音。一年打开几次的页面（发布会、年度报告、活动页）可以把装饰和动势放开。
3. **调性**。前两条定完下限，剩下的空间才交给品牌气质。

然后按设备和人群微调：手机上密度降一档；老人和孩子圆润 +1、点击区放大到 48px、字号 +2px；强光户外对比度再拉高，少用玻璃和细线。

|---|---|---|---|---|---|---|---|---|---|

## 5. 「高级感」检查表

高级感不是一种风格，是一组可检查的做法。交付前逐条过：

1. **色彩克制**：一个主色 + 带一点色相的中性色；主色面积约占 5–10%；大面积不用 `#000` / `#fff`（品牌明确要求时例外，要写明理由）。
2. **层级靠字号、字重和留白**，不靠把字调淡。次要文字也要 ≥4.5:1。
3. **一个尺度体系**：整页一套圆角、一套阴影、一套间距；嵌套圆角同心（内 = 外 − 内边距）。
4. **阴影带色相、分两层**（贴地的一层 + 环境的一层），不是一团黑雾。
5. **对齐到 4pt 网格**；数字用等宽数字（`tabular-nums`）。
6. **每个状态都设计过**：悬停、按下、聚焦、加载、空、错误、成功。见 feedback.md。
7. **动效短、有物理感、可打断**；拖拽 1:1 跟手。见 motion.md。
8. **一处值得记住的细节**，其余都安静。
9. **内容是真的**：真实文案长度、真实数据格式、真实 Logo；没有 lorem，没有编造的「47.2%」。
10. **删到删不动**：每个装饰都问一句「拿掉会少什么」，答不上就拿掉。

## 6. 避免千篇一律

- **第一层默认**：紫蓝渐变 + 玻璃卡片 + 三栏功能卡 + 居中大标题。
- **第二层默认**：为了躲开第一层，又全都变成米色纸张 + 衬线大标题。这也是模板。
- **换名测试**：把产品名换成竞品，页面还成立，说明风格没有从产品里长出来。
- 每个风格至少放一个**取自产品本身的元素**：票据产品用齿孔边，咖啡品牌用杯沿弧线，物流产品用路线虚线，记账产品用小票卷纸。
- 用户没定方向时，给 **3 个方向**，每个方向至少有 3 个旋钮明显不同。每个方向写一句话 + 7 个旋钮值 + 招牌细节，让用户一眼能挑。

## 7. 交付时这样写风格说明

```
定位：开发者 API 控制台，一天开很多次，涉及密钥和计费
旋钮：温 1 · 能 4 · 密 5 · 圆 2 · 景 3 · 动 4 · 装 3
推导：高频 → 密度 5、动效 ≤300ms；涉及密钥 → 关键操作不回弹、复制有明确回执；
      夜间使用多 → 暗色为主，只让关键数据发光
颜色：node scripts/palette.mjs --neutral 255 --tint 0.012 --accent 125 --chroma 0.19 --spice 295 --mode dark
字体：几何无衬线 + 等宽；中文用系统黑体
圆角：4 / 8 / 12px　　景深：暗面靠亮边分层　　动效：snappy
招牌细节：密钥「解码」出现（scramble），只在复制密钥时用一次
```
