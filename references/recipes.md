# 常见组件配方

kit 没覆盖的常见组件，按这里的要点做。数字是起点，跟着密度和圆润旋钮调整。每条都要套上 feedback.md 的四拍和状态矩阵。

## 输入与操作

- **按钮**：高 32 / 40 / 48（紧凑 / 默认 / 宽松），左右内边距约为高度的 0.4–0.5 倍。主按钮一屏只有一个；次要按钮用描边或淡底；文字按钮也要 44px 点击区。加载时保留宽度，文字换成转圈；危险操作用 `--c-bad`，按下不回弹。
- **输入框**：高 40–44，标签在上方，不要只用占位文字当标签（输入后标签就没了）。聚焦时边框变主色并加焦点环；错误时边框变红，下方一行写原因。手机上字号至少 16px；要有清空按钮、密码显示切换；`inputmode` 和 `autocomplete` 写对，手机才弹出合适的键盘。
- **下拉选择**：选项少于 5 个时改用分段控件或单选。桌面用浮层列表，键盘能上下选、能输入首字母跳转；手机用底部面板，或者干脆用原生 `<select>`。
- **分段 / 标签页**：指示器直接滑过去，大小不变，不拉伸（`A.glider`）；用方向键切换；标签页的内容区切换时淡入，不要整块滑。
- **开关**：点击区至少 44×24；滑块移动 + 底色变化 160–200ms；状态变化立刻生效，不需要额外的保存按钮；`role="switch"` + `aria-checked`。
- **复选 / 单选**：整行可点（用 `<label>` 包住）；对勾描边动画（`A.checks`）；半选状态用一条横线。
- **滑块**：拖动时显示数值气泡；拇指可见尺寸 20–28px，点击区 44px；方向键微调，PageUp / PageDown 大步调整。
- **步进器（± 数量）**：长按连续加减并逐渐加速；到上下限时按钮变灰并轻抖一下。

## 浮层

- **提示气泡 tooltip**：悬停 300–500ms 后出现，离开 100ms 后消失；键盘聚焦也要触发；触屏改成点按切换，或者把信息直接写在界面上。只放补充说明，不放必要信息。
- **弹出菜单 popover / menu**：从触发元素长出来（`transform-origin` 设在锚点），scale 0.96 → 1 加淡入 160ms；Esc 和点外面关闭，关闭后焦点回到触发元素；优先用原生 `popover` 属性或 `<dialog>`。
- **对话框 modal**：遮罩 40–60% 不透明度；焦点锁在框内，打开时聚焦第一个可操作元素；Esc 关闭（除非有未保存的输入）；手机上改成全屏页或底部面板；背后页面加 `inert`。
- **底部面板 sheet**：从 `translateY(100%)` 升起；顶部有拖动条，能拖下关闭（走过 1/3 或速度够快）；可以有 2–3 个停靠高度；背后的页面稍微缩小变暗，用户才知道它还在。
- **toast**：桌面在右下或顶部中间，手机在底部（避开安全区）或顶部；2.2–4s 自动消失，鼠标悬停时暂停；同时最多 3 条；`role="status"`。带「撤销」的 toast 停留 5s 以上。

## 数据与内容

- **骨架屏**：形状和真实内容一致；微光扫过 1.2–1.6s 一次，减少动态时只保留静态色块；300ms 内能加载完的就不显示骨架。
- **空状态**：一句话说明为什么是空的 + 一个主要按钮 + 一个示例预览（`aria-hidden`，标注「示例」）。第一次使用的空状态最重要。
- **表格**：表头固定；数字右对齐，用等宽数字；行悬停变底色；提供紧凑 / 舒适两档密度；操作按钮悬停才显示时，触屏上要常显。手机上改成卡片列表，或者首列固定、横向滚动。
- **卡片**：悬停只做一件事（抬起或亮边）；整卡可点时，用一个覆盖整卡的链接，卡里的其他按钮叠在上面；`minmax(0, 1fr)` 防止被长内容撑破。
- **头像组**：重叠 25–30%，每个头像外加 2px 底色描边；超出显示「+N」；悬停展开。
- **徽标 / 计数**：数字变化时弹一下（scale 1 → 1.3 → 1）；超过 99 显示「99+」；不要用颜色作为唯一提示。
- **图表**：用 data-1…6 取色；直接标注在线条末端，而不是只放图例；数据变化时柱子错开 20–30ms 过渡；坐标轴文字用 text-3；不画 3D 饼图。

## 导航

- **侧边导航**：桌面宽 220–260px，可折叠成 64px 的图标栏，折叠后悬停或聚焦显示标签；当前项用主色淡底 + 左侧指示条或填充图标。
- **底部 Tab**：3–5 项，每项至少 44px 高；图标 + 文字，选中换填充图标；加 `env(safe-area-inset-bottom)` 内边距；主要内容区的底部内边距要让出 Tab 的高度。
- **面包屑 / 返回**：手机上只留返回按钮 + 当前页标题。
- **命令面板（⌘K）**：打开时输入框自动聚焦；模糊匹配并高亮命中的字；上下键选择，回车执行；显示快捷键提示；最近使用的排在前面。
- **分页 / 无限滚动**：要能回到原来位置（返回时恢复滚动位置）；无限滚动的页面底部不放重要链接；加载下一页时在底部显示骨架。

## AI 与对话

- **流式输出**：文字逐段出现，末尾一个闪烁的光标；生成时显示「停止」按钮，点了立刻停，在下一帧里就要有反应；代码块带复制按钮。
- **思考 / 工具调用**：显示阶段和耗时（「检索中 · 2.1s」），可以展开看细节；失败的步骤原地给重试。
- **输入框**：随内容自动增高（最多 6–8 行）；回车发送、Shift+回车换行（手机上回车换行）；发送后输入框立刻清空，消息先以「发送中」状态出现在列表里。
- **模型选择**：厂商 Logo 用统一尺寸的单色版（icons-logos.md），模型名用等宽或系统字体，标出上下文长度和价格时用真实数字。

## 文件与时间

- **上传**：拖入时整个区域高亮并显示「松手上传」；每个文件单独显示进度、可取消；失败的文件原地重试；图片显示缩略图。
- **日期选择**：桌面用日历浮层，可以直接输入；手机用原生日期选择或底部滚轮（`A.wheel`）；常用范围给快捷按钮（今天、最近 7 天）。
- **时间显示**：用人的说法（「刚刚」「3 分钟前」「11月6日」），悬停显示完整时间；表格里用统一的完整格式。
