# 圆角、间距、景深、层级、焦点

## 1. 圆角：跟「圆润」旋钮走，一页只用一套

| 圆润 | 控件 `--r-control` | 卡片 `--r-card` | 面板 `--r-panel` | 示例 |
|---|---|---|---|---|
| 1 | 2–4px | 4–6px | 8px | 墨 Ink：3 / 6 / 8 |
| 2 | 6px | 10–12px | 16px | 夜航 Night：6 / 12 / 16 |
| 3 | 8px | 16–20px | 24–28px | tokens.css 默认：8 / 20 / 28 |
| 4 | 12px | 20–22px | 28px | 瓷 Porcelain：12 / 22 / 28 |
| 5 | 胶囊 999px | 24px | 30px | 团子 Dango：999 / 24 / 30 |

- **同心圆角**：内层圆角 = 外层圆角 − 内边距（最小 2px）。外框 20px、内边距 8px，里面的按钮就是 12px。不同心的嵌套圆角一眼就显得粗糙。
- **一个尺度**：组件只读 `--r-control / --r-card / --r-panel` 和 `--r-full`，不自己写数字。
- **胶囊**只给按钮、标签、开关、搜索框；卡片做成胶囊会很难排版。
- 头像、状态点用圆形；图片缩略图跟卡片圆角走，比卡片小一档。
- `corner-shape: squircle` 这类超椭圆圆角只算渐进增强，不支持的浏览器自动退回普通圆角。

## 2. 间距：4pt 网格

tokens.css：`--s-1` 4 · `--s-2` 8 · `--s-3` 12 · `--s-4` 16 · `--s-5` 24 · `--s-6` 32 · `--s-7` 48 · `--s-8` 64 · `--s-9` 96

| 密度 | 控件视觉高度 | 列表行高 | 卡片内边距 | 区块间距 |
|---|---|---|---|---|
| 1–2 宽松 | 48–52 | 64–72 | 28–32 | 96–144 |
| 3 舒适 | 40–44 | 48–56 | 20–24 | 72–96 |
| 4–5 紧凑 | 32–36 | 32–40 | 12–16 | 48–64 |

- **组内间距约为组间间距的一半**，用户才分得清哪些东西是一组的。
- **视觉高度可以小于 44px，点击区不行**：触屏上用透明的 `::before` 把点击区撑到 44×44（tokens.css 的 `--tap`），相邻目标留 8px。
- 页面左右边距 `--gutter: clamp(16px, 4vw, 40px)`；区块间距 `--section: clamp(72px, 10vw, 144px)`；内容最大宽度 `--content: 1200px`。
- **光学修正**：带图标的按钮，图标那一侧内边距少 2–4px；胶囊按钮的左右内边距约为高度的 0.4–0.5 倍；数字列右对齐。
- 网格用 `minmax(0, 1fr)` 而不是裸的 `1fr`，长单词、长链接才不会把列撑破。

## 3. 景深：跟「景深」旋钮走

| 景深 | 分层手段 | 写法（摘自 examples/showcase/css/theme.css） |
|---|---|---|
| 1 | 只用细线和底色差 | `box-shadow: 0 0 0 1px var(--c-line)`；悬停换成 `--c-line-strong` |
| 2 | 细线 + 很轻的阴影 | `--sh-1`；悬停升到 `--sh-2` |
| 3 | 双层阴影，悬停抬起、按下贴平 | `--sh-2` → 悬停 `--sh-3` + `translateY(-2px)` → 按下回到 `--sh-1` |
| 4 | 磨砂玻璃 + 高光描边 | 底色 `color-mix(in srgb, var(--c-surface) 72%, transparent)`，`backdrop-filter: blur(20px) saturate(1.6)`，`inset 0 0 0 1px rgb(255 255 255 / .7)` |
| 5 | 实色投影、3D、视差 | 团子：`0 0 0 2px var(--c-text), 4px 5px 0 0 var(--c-text)`；按下时投影归零、元素平移 4px 5px，像被按扁 |

### 阴影
- **两层**：一层贴地的短阴影（1–2px）负责「落在桌上」，一层大而淡、带负扩散的环境阴影负责「浮起来」。tokens.css 的 `--sh-2`、`--sh-3` 就是这么写的。
- **带色相**：阴影色用 `--c-shadow-c`（中性色相的深色），不用纯黑。
- **高度要有意义**：静止 < 悬停 < 弹层 < 拖拽中。拖拽中的元素阴影最大，并且稍微放大（1.02–1.04）。
- **深色模式**：阴影几乎看不见。改用更亮的表面 + 顶部亮边 `--hl-inset`；发光只留给一个重点（主按钮、关键数字）。

### 玻璃
- 只用在**浮在内容上**的东西：顶栏、底部 Tab、工具条、弹层、底部抽屉。下面没有内容透出来的玻璃，就是一块灰。
- 文字对比度按**最差的背景**算；不够就提高底色不透明度。
- 不支持 `backdrop-filter` 时退回实色 surface；`@media (prefers-reduced-transparency: reduce)` 也退回实色。
- 同屏可见的模糊层不超过 2–3 层，大面积模糊很费 GPU，低端手机会掉帧。

### 线还是阴影
选一种当主要分层手段，另一种只做辅助。线适合高密度的工具界面，阴影适合低密度的内容界面。两者同时用满会显得脏。

## 4. 层级 z-index

tokens.css：`--z-raise` 1 · `--z-sticky` 20 · `--z-overlay` 40 · `--z-toast` 60 · `--z-cursor` 80

- 只用这几个值，不写 9999。
- 组件内部的层叠用 `isolation: isolate` 关在组件里，不跟页面抢。
- 弹层挂到 body 下，或者用原生 `<dialog>` / `popover` 进入顶层，不跟父元素的 `overflow` 和 `transform` 打架。

## 5. 焦点环

- 只在键盘操作时出现：`:focus-visible`。
- tokens.css：`--focus: 0 0 0 2px var(--c-bg), 0 0 0 4px var(--c-accent)`，先一圈底色间隙，再一圈主色。用 box-shadow 画的环会自动跟着圆角走。
- Windows 高对比度模式会去掉 box-shadow，所以同时保留 `outline: 2px solid transparent`，系统会把它画出来。
- 焦点环和背景至少 3:1。
- 不同状态之间边框宽度不变，焦点环用阴影或预留的 outline，布局才不会跳。
- 焦点环不做动画，瞬间出现。
