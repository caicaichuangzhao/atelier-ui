# 特效：选对、选少、搭得合理

不是每个风格都要上所有特效。特效像调味：一道菜一个主味，其余是底味。

## 1. 预算

- **每页最多 1 个招牌特效 + 2 个环境特效**。交互反馈（按下、对勾、滚动数字）不算预算，但要安静。
- 招牌特效：首屏粒子文字、可拖的 3D 物体、着色器背景，用户记住这一页靠它。
- 环境特效：底纹、聚光、轻微视差，用户不会特意注意，但会觉得「有质感」。
- **同一块区域只叠 1 个指针特效**。磁吸 + 倾斜 + 聚光放在同一张卡上，三个效果会打架（pointer.js 里也写了这条）。
- 悬停最多「1 种位移 + 1 种光」：抬起 + 亮边可以；抬起 + 倾斜 + 放大 + 辉光不行。
- 跟「装饰」旋钮走：1 没有特效；2 一个安静的招牌；3 招牌 + 1 个环境；4 招牌 + 2 个环境；5 可以加粒子、贴纸、插画，但招牌仍然只有 1 个。
- **信任页面不放特效**：付款、设置、隐私、错误页（404 可以例外，做得好玩一点）。

## 2. 成本档

| 档 | 技术 | 什么时候用 |
|---|---|---|
| CSS | transform、opacity、渐变、`mask` | 默认，先想 CSS 能不能做 |
| SVG 滤镜 | `feTurbulence`、`feDisplacementMap`、goo 滤镜 | 只给小面积；每帧都重新栅格化，大面积很卡 |
| Canvas 2D | 粒子、拖尾、点阵 | 用 `Atelier.loop` 控制停帧；像素比封顶 2 |
| WebGL | 着色器背景、流体 | 只给首屏招牌，并准备静态降级图 |
| 3D / 物理引擎 | three.js、matter-js | 产品本身就是 3D，或者这页的核心玩法就是它 |

## 3. 特效家族：好的用法与廉价用法

| 家族 | 好的用法 | 廉价用法（别这样做） |
|---|---|---|
| 文字出现（拆字、错开） | 标题入场一次，30–50ms 错开 | 每一段文字都淡入上移 |
| 乱码解码 scramble | 短的英文或等宽标签：密钥、版本号、状态 | 中文正文（中文用淡入） |
| 粒子文字 | 首屏一句话，可以被指针拨开 | 整页漂浮的粒子连线「星座」 |
| 扫光 shine | 「新」标签扫一次 | 每个按钮常驻流光 |
| 滚动数字 odometer | 数据真的变化时滚一次 | 每次进入页面都从 0 数上来 |
| 磁吸 magnetic | 1–2 个主行动按钮 | 所有链接都会被吸 |
| 聚光 / 亮边 spotlight | 一组卡片共用一束光 | 每张卡各发各的光 |
| 倾斜 + 反光 tilt | 商品卡、会员卡、作品封面 | 正文卡片、表单 |
| 指针拖尾 ribbon | 有边界的画板或首屏区域 | 全页光标尾巴压在正文上 |
| 背景氛围（极光、网格、噪点） | 首屏一处，静止也好看 | 每个区块换一种背景 |
| 玻璃 | 浮在内容上的导航和工具条 | 「玻璃卡片」底下什么都没有 |
| 视差 | 1–2 层，幅度 ≤40px | 五层视差，滚动发晕 |
| 3D 卡片滚动（MacBook 打开那种） | 发布会式的单品页 | 后台工具 |

## 4. 按定位搭配

| 定位 | 招牌 | 环境 | 避开 |
|---|---|---|---|
| 墨 Ink（编辑） | 墨点粒子文字 | 笔锋拖尾、纸纹点阵 | 辉光、玻璃、回弹 |
| 夜航 Night（开发者） | 辉光粒子 | 光迹拖尾、聚光数据格、密钥解码 | 回弹、彩纸、暖色渐变 |
| 团子 Dango（年轻社区） | 彩纸粒子 | 团子串拖尾、完成迸发、实色投影 | 玻璃、冷色细线 |
| 瓷 Porcelain（硬件） | 渐变柔光粒子 | 磨砂玻璃、倾斜反光 | 粗描边、彩纸、高饱和 |
| 金融 / 医疗 | 不要招牌，或只有一个滚动数字 | 极淡的底纹 | 粒子、拖尾、回弹 |
| 活动页 / 游戏 | 着色器背景或 3D | 文字出现、视差 | 后台式的密集表格 |

## 5. 粒子文字规格（`Atelier.particles`）

- 把文字画到离屏 canvas，`getImageData` 取样成点。点数预算：桌面约 3200，屏宽 <640px 约 1500（按笔画面积自动算取样间隔）。
- 每个点用弹簧回家（k 0.055、阻尼 0.86，每帧）；指针附近的点被推开并带一点旋转；点按会炸开（触屏力度 0.6）；`setText()` 时点在新旧字形之间迁移。
- 像素比封顶 2；元素离开视口或标签页隐藏时停帧；用 ResizeObserver 重新取样。
- 先等字体加载（最多等 2 秒），否则取样到的是回退字体的形状。
- 画法：`paint: 'ink' | 'gradient' | 'confetti'`，`shape: 'square' | 'round'`，`blend: 'lighter'` 用于暗底发光，`twinkle` 让少量点闪烁。
- 可访问：真实文字留在 DOM 里给读屏和搜索引擎，canvas 加 `aria-hidden="true"`。
- 减少动态：直接画出静止的字形，不动。

## 6. 指针拖尾规格（`Atelier.ribbon`）

- 拖尾在 `life` 秒内消散（默认 0.5s）；速度越快线越细，像毛笔提笔；尾端收尖并变透明。
- 三种笔触：`brush` 墨色笔锋，`glow` 叠加发光（暗底），`beads` 一串彩色圆珠。
- 只放在有边界的区域里；触屏上不启用（手指下面本来就看不见）。

## 7. 其他规格

- **乱码解码**（`Atelier.scramble`）：字符依次从左往右锁定，约 700ms；只用于拉丁字母和等宽文字。
- **滚动数字**（`Atelier.odometer`）：每一位是一条 0–9 的竖条，个位先动，高位依次晚 45ms；读屏读到的是普通数字。
- **聚光**（`Atelier.spotlight` + pointer.css）：边框用 mask 只露出 1px 亮边，光圈半径 220px，内部再铺一层极淡的主色光晕；指针离开整组后 0.4s 淡出。
- **倾斜**（`Atelier.tilt`）：最大 7°，`perspective(900px)`；反光层用 `mix-blend-mode: soft-light`。
- **字重随指针变化**（Text Pressure 一类）：需要可变字体的字重或字宽轴，中文可变字体很少而且很大，基本只适用于拉丁字母。
