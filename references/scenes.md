# 交互动画场景：什么项目、什么时候、搭什么

effects.md 管「每页放几个特效」，这里管更大的一件事：**一页的招牌交互动画怎么从产品里长出来，怎么搭**。研究对象是 motionsites.ai 上 19 个动效网站模板的公开预览录屏（2026-11-10 用 REA 抓取，只看了公开预览，没有复制任何提示词文本或代码），结论是我们自己的归纳。

## 1. 好模板的共同结构

把 19 个模板拆开看，做得好的都满足这六条：

1. **一页一个物理隐喻**。轨道球、挂衣架、全息布料、粒子大脑、霓虹面罩：整页只围绕一个「东西」。别的模块都安静。
2. **用户直接摆弄那个东西**。能拖着转、抓起来甩、擦掉一层、按着拉。只是「看着它动」的，只能算背景。
3. **文字始终是真 DOM、压在场景上**。大标题、导航、正文都是 HTML 文字，叠在 3D / 视频 / canvas 上方；场景是装饰，信息在 DOM 里。
4. **静止时就成立**。第一帧就是一张构图完整的海报；动画是第二层奖励，不是加载完才有意思。
5. **滚动推进叙事，指针负责玩**。分工清楚：滚动换「章节」（物体变形、镜头转场、视角切换），指针在每一章里做局部扰动（推开粒子、拨动布料）。
6. **点击 = 进入详情**。轨道球点一张图就飞到屏幕中央放大，其他卡退后；收起时原路回去。这是共享元素过渡，不是弹窗。

## 2. 交互模型（招牌动画的 8 种「玩法」）

| 模型 | 用户做什么 | motionsites 里的例子 | 技术底座 | kit 起点 |
|---|---|---|---|---|
| 轨道 Orbit | 拖着转一个由卡片组成的球 / 环 / 圆柱，点一张飞出来 | Orbit Sphere、Card Story（卡片环 → 圆柱 → 斜铺网格） | CSS 3D（`preserve-3d`）或 three.js；拖拽带惯性 | `A.orbit`（fx/orbit.js） |
| 揭开 Reveal | 指针擦过一层，露出下面那层 | Ink Reveal（墨团跟随，字变白）、Grid Runner（擦掉面罩露出人脸，松手慢慢长回去） | canvas 当遮罩 + `mask-image`，或 WebGL 流体 | `A.scratch`（fx/scratch.js） |
| 扰动 Disturb | 指针推开 / 拨动一群东西，松开回家 | Particle Brain（粒子被拨开）、Saffron Field（粒子在花朵 / 圆环 / 蝴蝶 / 宝石之间变形） | 粒子 + 弹簧回家；形状来自采样 | `A.particles`（fx/particles.js） |
| 抓取 Grab | 抓起一块物体，它跟手、甩出、带物理感回弹 | Peculiar Atelier（布料被抓起、翻卷、落回）、Orbit Stickers（贴纸被拖出、轻轻落回原位） | 布料要 WebGL；贴纸用 DOM + 弹簧就够 | `A.spring` + pointer 跟手（motion.md 第 5 节） |
| 拼贴 Collage | 一堆卡片 / 贴纸散落、叠放、悬停浮起 | Stridr（运动杂志拼贴，卡片依次落下）、Orbit Stickers | DOM 卡片 + 错开落下 + 悬停抬起 | `A.flip` / `A.stack` / `A.split` 的错开 |
| 架子 Rail | 一排商品挂在架上，镜头推近，悬停的那件放大 | Loops Virtual Store（衣架从远到近，悬停一件） | 横向列表 + 镜头缩放；可以纯 CSS | `A.marquee` + 悬停 scale |
| 场景切换 Switch | 一个开关改变整个场景的状态 | Lumen Roof（早 / 晚切换，雾气盖住再散开，房子换光） | 两张图交叉 + 遮罩转场 | `A.segmented` + `A.transition` |
| 编排 Choreo | 滚动驱动一个主角做「运镜」：侧面 → 俯视 → 拆解 | Roadster 3D（跑车 360° 转，俯视时两侧出参数卡）、Jellyfish（水母随滚动，大字逐词滑过） | 预渲染图序列 / 视频 scrub / three.js 模型 | `A.progress` 驱动帧序列或 3D |

## 3. 按项目选玩法

| 项目 | 首选玩法 | 理由 | 别用 |
|---|---|---|---|
| 摄影 / 作品集 / 创意机构 | 轨道、拼贴、编排 | 作品就是内容，让人「翻」作品 | 粒子大脑（信息太抽象） |
| 电商（服饰、潮牌） | 架子、轨道、抓取 | 商品要能被「拿起来看」 | 揭开（会挡住商品） |
| 汽车 / 硬件 / 单品发布 | 编排（滚动运镜） | 一件产品多个角度，滚动当转盘 | 拼贴（显得廉价） |
| AI / 知识产品 | 扰动（粒子成形）、揭开 | 「信息碎片聚合」是天然隐喻 | 抓取布料（和产品无关） |
| 新能源 / 家居 / 生活方式 | 场景切换 | 用户想看的是「不同状态下的样子」 | 粒子 |
| 游戏 / 影视 / IP | 揭开、编排 | 角色和世界观需要「被发现」 | 后台式克制 |
| 艺术 / 展览 / 文化 | 拼贴、轨道、慢编排 | 节奏慢、留白多 | 高能量回弹 |
| 开发者 / 数据产品 | 扰动（点阵）、编排一个架构图 | 精确、可读 | 抓取、贴纸 |
| 金融 / 医疗 / 政务 | **不放招牌交互**；最多一个滚动数字或线条描绘 | 信任优先（positioning.md 第 3 节） | 所有招牌玩法 |
| 后台 / 工具 / 控制台 | 不放；反馈动效足够 | 高频使用，惊喜会变噪音 | 所有招牌玩法 |

## 4. 什么时候放

- **首屏**：招牌玩法只放在首屏或一个专门的「体验段」。正文区、表单区、价格区保持安静。
- **一页最多两个高潮**：首屏一个，中段或页尾最多再一个（比如页尾贴纸、价格前的场景切换），并且两个用不同的玩法。
- **滚动叙事 3–6 章**：每章一个画面状态 + 一句话。超过 6 章用户会迷路，并且要有进度指示（侧边编号、底部进度条）。
- **转场前后给「读」的时间**：一个状态至少停留 1 屏高度的滚动距离，再进入下一章。
- **页尾彩蛋**：页尾是放松的地方，适合贴纸、可拖物体这种「玩一下」的小交互。

## 5. 怎么搭（工程骨架）

```
<section class="stage">                 ← 有边界的舞台，position: relative; isolation: isolate
  <canvas | div.scene aria-hidden>      ← 场景层：只负责好看，读屏忽略
  <div class="copy">                    ← 文字层：真 DOM，标题、按钮、说明
  <nav class="chapters">                ← 进度 / 章节指示（滚动叙事时）
```

1. **先做静态海报**：场景第一帧 + 文字排版要先成立，再加动。没有 JS、减少动态时就停在这一帧。
2. **场景状态 = 一个数字**：滚动进度 `p`（0→1）或指针位置决定场景，渲染函数只读这个数字。这样可以随时跳章、倒放、打断。
3. **输入层分离**：指针 / 拖拽 / 滚动只更新目标值，渲染循环（`A.loop`）用弹簧追目标。输入停了，循环自己睡。
4. **点击详情走共享元素**：被点的卡从场景里的位置和大小长到详情位置（`A.morph` 或 FLIP），关闭时原路回去，焦点回到那张卡。
5. **触屏降级**：拖拽仍然可以（单指拖转、`touch-action: pan-y` 让纵向滚动不被吃掉）；悬停才有的东西改成点按；粒子数和卡片数减半。
6. **成本上限**：同屏只有这一个重场景；离开视口停帧；像素比封顶 2；低端设备用预渲染视频或静态图代替。

## 6. 资产从哪来

- 这些模板好看，一半靠**素材**：统一风格的 3D 渲染图、同一色调的照片、同一画师的贴纸。
- 没有素材时：用 image-prompts.md 生成一组**同一提示词骨架、只换主体**的图（同光线、同背景、同色调），或者用纯排版 + 几何图形代替照片。
- 不要混用风格不同的图：一张写实照片 + 一张扁平插画放在同一个轨道球里，立刻廉价。
- 视频背景：给 poster 静帧，`muted playsinline loop`，离屏暂停；文字压在视频上要有渐变遮罩保证对比度。

- [ ] 静止第一帧就是好海报；减少动态时停在这一帧
- [ ] 文字都是 DOM，对比度按最差的背景算
- [ ] 触屏上有对应的玩法，不是只剩一张图

- [ ] 点开的详情能关、能用键盘、焦点能回去
